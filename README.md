# Food App Threads

Android application που υλοποιεί πολυνηματικότητα (threads) και client-server επικοινωνία.  
Φτιάχτηκε στο Android Studio.

---

## 🚀 Χαρακτηριστικά
- Διαχείριση threads σε Android
- Χρήση `Handler` για επικοινωνία μεταξύ νημάτων
- Δομή σε modules:
  - **app/**: Android UI & activities
  - **backend/**: Java classes για λογική και worker threads
- Παραδείγματα:
  - Εισαγωγή προϊόντων
  - Διαχείριση παραγγελιών
  - Αναφορές πωλήσεων

---

## 🛠️ Απαιτήσεις
- **Android Studio Arctic Fox ή νεότερο**
- **Gradle** (περιλαμβάνεται στο project)
- **Java 8+**
- Android Emulator ή συσκευή με API 24+ (Android 7.0)
